# data/orbits — SELENE periodic-orbit library (Earth–Moon CR3BP)

Generated by `python -m selene.orbits.library --rebuild` (≈ 5 s wall on 8 cores, ≈ 30 s CPU).
All orbits are solutions of the circular restricted three-body problem with
μ = GM_Moon/(GM_Earth+GM_Moon) from DE440 (0.0121505844), L* = 384 400 km,
T* = sqrt(L*³/(GM_E+GM_M)) ≈ 375 190 s.  In the real (DE440s) force model they are
quasi-periodic reference orbits, not exact solutions.

| file | content |
|------|---------|
| `orbits.parquet` | one row per orbit record: `id, family, branch, index, x0..vz0` (rotating frame, nondimensional), `period_nd, period_days, jacobi, stability_index, closure_error, method`, JSON columns `eigenvalues` (|λ| of the monodromy matrix), `params` (perilune/apolune/perigee/apogee km, Az/Ax/Ay km, …), `tags` |
| `families.json` | build metadata (μ, L*, T*, timestamp, conventions) and per-family generation parameters, counts, ranges and literature references |
| `jpl_reference.json` | compact subset (≤ 60 members per family + a ~700-vertex (Jacobi, period) poly-line sampled uniformly in catalogue index *and* in arc length, plus the extremal members so it reaches the catalogue limits, e.g. the L1 halo period fold at T = 1.80367) of JPL's Three-Body Periodic Orbit Catalog for the same families, with query URLs and access date; used by `tests/test_orbits_jpl.py` |

Families: `L1_lyapunov`, `L2_lyapunov`, `L1_halo` (N/S), `L2_halo` (N/S), `DRO`,
`resonant_3:1`, `resonant_2:1`.  Tags of note: `NRHO` (members inside the published
near-rectilinear stability bounds), `NRHO_9:2`, `NRHO_4:1`, `NRHO_3:1` (L2 southern members
whose period equals q/p synodic months, found by root-finding along the family),
`stable` (stability index ≤ 1 + 1e-6), `planar`, `DRO`, `RESONANT_p:q`.

Initial-condition convention: the perpendicular xz-plane crossing farther from the Moon
(apolune for NRHOs); halo branch N/S is the sign of z there.

Geometry parameters (`perilune_km`, `apolune_km`, `perigee_km`, `apogee_km`) are refined by a
bounded 1-D minimisation on the integrator's dense output, not read off a time grid: the
perilune passage of a near-rectilinear halo lasts hours out of a week and a 600-point grid
minimum is biased high by up to ~400 km, which in an earlier build hid sub-surface L1 halo
members.  Halo families terminate at perilune < R_moon + 50 km (refined value), so no record
is a lunar impactor (lowest perilune: L1 halo 1 961 km, L2 halo 1 901 km).

Closure error is |X(T) − X0|∞ from an independent DOP853 propagation at rtol = 2.3e-14,
atol = 1e-14 (the tightest scipy accepts).  Measured at the corrector's own rtol = atol = 1e-12
the same ICs show up to ~9e-10 for the most unstable Lyapunov members (|λ_max| ≈ 1e3 amplifies
the integration error), so the quoted figures (< 1e-10 for all single-shooting records,
< 1e-9 for multiple-shooting NRHO members) refer to the 2.3e-14 measurement.  Resonant
members get a final corrector pass with the integrator at the same tight tolerance, and the
families stop at perigee ≈ 50 000–63 000 km (x0 = 0.12 / 0.15) where the closure check
reaches its double-precision roundoff floor (~1e-10 even for a perfectly converged IC).

JPL catalogue normalisation differs from SELENE's (lunit 389 703 km, tunit 382 981 s, μ differs by
1.2e-9); dimensionless initial conditions, periods and Jacobi constants are directly comparable,
km/day values are not.  See `backend/selene/orbits/jpl_reference.py`.
